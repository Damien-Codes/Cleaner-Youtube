# Chaînes YouTube cibles — une URL par ligne.
# Les lignes vides et celles commençant par « # » sont ignorées.
# Un commentaire en fin de ligne est possible : https://www.youtube.com/@exemple  # ma note
#
# Formats acceptés :
#   https://www.youtube.com/@handle
#   https://www.youtube.com/channel/UCxxxxxxxxxxxxxxxxxxxxxx
#   https://www.youtube.com/c/NomPersonnalise
#   https://www.youtube.com/user/AncienNomUtilisateur
#   @handle            (forme courte)
#   UCxxxxxxxxxxxxxxxxxxxxxx   (channelId seul)
#
